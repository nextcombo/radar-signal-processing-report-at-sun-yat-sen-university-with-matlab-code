# Radar Signal Processing Report at Sun Yat-sen University [with MATLAB Code]

Simulation Requirements:
1.1 Analysis of LFM Signal:
- (1) Simulate an LFM signal;
- (2) Observe the DFT results under different oversampling rates;
- (3) Observe the spectrum of the LFM signal with different TBPs.

2. Impulse Compression Simulation: For "Baseband LFM Signal":
- (1) Implement error-free impulse compression, calculate metrics (IRW, PSLR, ISLR);
- (2) Observe the impact of frequency domain windowing, calculate metrics (IRW, PSLR, ISLR).

3. LFM Backscattering Simulation:
- (1) Input parameters: Target parameters: RCS equal to 1, located at 15Km and 16Km. LFM signal parameters: Center frequency 5.0GHz, pulse width 30us, bandwidth 30MHz. Receiver parameters: The receiver starts receiving signals after 0.1ms after the transmission signal is initiated, lasting 0.04ms, sampled at a factor of 1.2 oversampling.
- (2) Output: Complete impulse compression.
